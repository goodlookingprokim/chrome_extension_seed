• 눈이 편안한 보라색 그라데이션 배경

• 기본 새 탭이 심심하게 느껴지는 분

🔒 개인정보 보호
• 어떠한 개인정보도 수집하지 않습니다
• 인터넷 연결 없이도 완벽하게 작동합니다
• 광고가 전혀 없습니다

노자, 공자, 아리스토텔레스, 괴테 등 동서양 현인들의 지혜를 매일 만나보세요. 작지만 의미 있는 변화가 당신의 하루를 바꿀 수 있습니다.

## 🔒 2. Privacy (개인정보)

### 2.1 Single Purpose Description (단일 목적 설명)

```
이 확장 프로그램은 Chrome의 새 탭 페이지를 영감을 주는 명언 화면으로 대체합니다.
```

또는 영어로:
```
This extension replaces Chrome's new tab page with an inspiring daily quote display.
```

---

### 2.2 Permission Justification (권한 정당화)

우리 확장 프로그램은 특별한 권한을 요청하지 않습니다.

만약 권한 관련 질문이 나오면:

| 권한 | 설명 |
|------|------|
| **chrome_url_overrides (newtab)** | 새 탭 페이지를 명언 화면으로 대체하기 위해 필요합니다 |

---

### 2.3 Privacy Practices (개인정보 관행)

**Data Collection (데이터 수집) 섹션에서 다음을 선택하세요:**

```
☑️ 이 확장 프로그램은 사용자 데이터를 수집하거나 사용하지 않습니다.
   (I certify that this extension does not collect or use any user data.)
```

**왜 이 옵션인가요?**

| 체크 항목 | 우리 확장 프로그램 |
|----------|-------------------|
| 개인 식별 정보 수집 | ❌ 없음 |
| 건강 정보 수집 | ❌ 없음 |
| 금융 정보 수집 | ❌ 없음 |
| 인증 정보 수집 | ❌ 없음 |
| 개인 통신 수집 | ❌ 없음 |
| 위치 정보 수집 | ❌ 없음 |
| 웹 기록 수집 | ❌ 없음 |
| 사용자 활동 수집 | ❌ 없음 |
| 웹사이트 콘텐츠 수집 | ❌ 없음 |

**모든 데이터가 로컬에서만 처리됩니다. 서버 통신이 전혀 없습니다.**

---

### 2.4 Privacy Policy (개인정보처리방침)

데이터를 수집하지 않으므로 **별도의 개인정보처리방침 URL이 필요하지 않습니다.**

하지만 입력을 요구하는 경우, 아래 내용으로 GitHub Gist나 개인 페이지에 올리세요:

```
개인정보처리방침 (Privacy Policy)

"오늘의 명언" 확장 프로그램

최종 수정일: 2024년 12월

1. 수집하는 정보
본 확장 프로그램은 어떠한 개인정보도 수집하지 않습니다.

2. 정보의 사용
수집하는 정보가 없으므로, 사용하는 정보도 없습니다.

3. 정보의 공유
수집하는 정보가 없으므로, 공유하는 정보도 없습니다.

4. 데이터 저장
본 확장 프로그램은 모든 데이터를 사용자의 로컬 기기에서만 처리합니다.
외부 서버와의 통신이 전혀 없습니다.

5. 문의
질문이 있으시면 [이메일 주소]로 연락주세요.
```
